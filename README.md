# Santiago Labarca — portfolio

The interactive version of my résumé: results grouped by competency, the software I've built,
and a bit about me. Static HTML/CSS/JS, no framework, no build step.

- `content.js` — every piece of copy and data
- `app.js` — renders it
- `styles.css` — design tokens (light/dark) and layout

Run locally: `python3 -m http.server 4322` and open http://localhost:4322.
